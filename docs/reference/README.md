# Reference

## Why This Folder Exists

This folder contains **reference material** for MechAI: the project glossary, useful links, and the open questions tracker. It exists so that shared vocabulary and resources are consistent and discoverable.

## Documents in This Folder

| Document | Purpose |
|----------|---------|
| [`01-project-glossary.md`](01-project-glossary.md) | The shared vocabulary of the project. |
| [`02-useful-links.md`](02-useful-links.md) | Curated links to external resources. |
| [`03-open-questions.md`](03-open-questions.md) | The tracker of open questions (agent-facing). |

## How to Use This Folder

1. **Unsure what a term means?** Check the [Glossary](01-project-glossary.md).
2. **Looking for a resource?** Check the [Useful Links](02-useful-links.md).
3. **Tracking an open question?** Use the [Open Questions](03-open-questions.md) tracker.

## Relationship to Other Folders

- **Risk** ([`../risk/`](../risk/)) tracks known unknowns at the project level.
- **Research** ([`../research/`](../research/)) resolves open questions.
- **Agents** ([`../agents/`](../agents/)) use the open questions tracker to coordinate.

*This folder is a living part of the repository. Reference material is maintained as the project evolves.*
