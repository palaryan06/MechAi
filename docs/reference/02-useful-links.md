# Useful Links

## Why This Document Exists

This document is a **curated collection of external resources** useful to the MechAI team. It exists so that valuable references are discoverable and shared, rather than scattered across chats and bookmarks.

## How to Use This Document

- **Browse** the categories for relevant resources.
- **Add** new resources as you find them, with a brief note on why they're useful.
- **Keep it curated** — only add resources that are genuinely useful.
