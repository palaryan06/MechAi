# Roadmap

## Why This Folder Exists

This folder contains the **MechAI roadmap**. The roadmap translates the vision and mission into concrete, prioritized milestones. It answers: *What are we building next, and in what order?*

The roadmap is the bridge between the mission (near-term direction) and the sprints (weekly work). It keeps the team aligned on priorities.

## How the Roadmap Works

```
Mission (docs/02-mission.md)
    ↓
Roadmap (this folder) — what milestones, in what order
    ↓
Sprints (docs/processes/05-sprint-workflow.md) — what this week
    ↓
Tasks (docs/processes/04-task-workflow.md) — specific units of work
```

## Roadmap Principles

1. **Aligned with the mission.** Every milestone serves the mission.
2. **Milestone-based.** The roadmap is organized into phases, not an endless feature list.
3. **Prioritized.** We do the most important thing next.
4. **Living.** The roadmap is updated as we learn.
5. **Realistic.** We commit to what we can actually achieve.

## Current Focus (Seed)

The current focus is summarized in the [Mission](../02-mission.md): **build the engineering foundation and reasoning architecture.** The roadmap reflects this — foundation first, research second, prototype third.

## How to Use This Folder

1. **Before planning sprints**, read the roadmap to understand priorities.
2. **When proposing new work**, link it to a roadmap item.
3. **When the mission shifts**, update the roadmap and record the change.
